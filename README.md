# PC Assembly Configurator

A web application for configuring custom PC builds with AI-powered recommendations.

## Features
- Component selection (CPU, GPU, RAM, SSD, PSU)
- Compatibility validation
- Price calculation
- AI-powered build recommendations
- Responsive design

## Tech Stack
- Backend: PHP, MySQL
- Frontend: HTML5, CSS3, JavaScript
- AI Integration: Claude API for recommendations
- Hosting: Hostinger

## How It Works

### 1. Component Selection
- Browse categorized components (CPU, GPU, RAM, SSD, PSU, Case, Cooling)
- Filter by price, brand, performance tier
- View detailed specifications for each component

### 2. AI Recommendations
- Describe your use case (gaming, streaming, 3D rendering, etc.)
- Set your budget
- Get AI-powered component suggestions optimized for your needs

### 3. Compatibility Check
- System validates component compatibility
- Checks PSU wattage vs system requirements
- Verifies socket compatibility, RAM type, etc.

### 4. Performance Estimate (Planned)
- FPS predictions for your favorite games
- Graphics settings recommendations
- Bottleneck analysis (CPU vs GPU)

### 5. Share & Export
- Get a shareable link to your build
- Export as PDF or spreadsheet
- Compare with other builds
